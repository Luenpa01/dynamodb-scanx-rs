# dynamodb-scanx-rs
DynamoDB ScanX rompe los límites del GIL de Python llevando el escaneo paralelo de DynamoDB a la era de la concurrencia sin miedo. Diseñado para operaciones masivas de bases de datos, migraciones SRE y análisis de datos en la terminal, ofreciendo un rendimiento nativo en Rust con integraciones fluidas para Python
